# متجر فولت إدج للأزياء الفاخرة (VoltEdge Fashion Store)

موقع ديمو احترافي وثابت (Static Website) لمتجر أزياء وإكسسوارات مصري راقٍ، ثنائي اللغة (عربي افتراضي + إنجليزي)، مصمم بألوان كريمية وبيج وبرونزية أنيقة، ومخصص للعمل مباشرة على **GitHub Pages** دون الحاجة لأي أدوات بناء أو بيئة تشغيل برمجية معقدة.

---

## 🌟 مميزات الموقع التقنية والتصميمية

1. **تقنيات ويب قياسية ونقية 100%**:
   - HTML5 دلالي + CSS3 حديث بمتغيرات الألوان والتصميم المرن + JavaScript Vanilla نظيف.
   - بدون React أو Vite أو Tailwind أو PHP، لضمان استقرار التشغيل والسرعة الفائقة.
   - مسارات نسبية كاملة (`./`) لتعمل الروابط والصور على GitHub Pages بسلاسة.

2. **تجربة استخدام متوافقة مع السوق المصري**:
   - العملة بالجنيه المصري (**ج.م / EGP**).
   - توجيه الطلبات والاستفسارات مباشرة عبر **واتساب** (`wa.me/20XXXXXXXXXX`) برسالة جاهزة تتضمن اسم القطعة، اللون المختار، المقاس، والسعر.
   - شحن لكافة المحافظات المصرية ومعاينة الشحنة قبل السداد، مع خيار الدفع عند الاستلام.
   - لا يحتوي الموقع على بوابات دفع إلكترونية أو حسابات، بل يوفر تجربة شراء راقية وسلسة.

3. **ثنائي اللغة بالكامل (العربية والإنجليزية)**:
   - دعم كامل للاتجاهين (RTL افتراضياً مع LTR للإنجليزي).
   - قاموس نصوص شامل في `js/data.js`.
   - زر تبديل سلس وسريع مع حفظ التفضيل في `localStorage`.

4. **فيديو هيرو ديناميكي**:
   - خلفية قسم الهيرو فيديو خفيف وسريع (`./videos/hero-video.mp4`) مع بديل صورة ثابتة (`./images/hero-main.jpg`).
   - يدعم الوضع الخفيف وخفض الحركة (`prefers-reduced-motion`) وحفظ البيانات (`Save-Data`).

## ⚙️ طريقة تخصيص البيانات والأسعار من ملف `js/data.js`

جميع محتويات المتجر تم جمعها في ملف مركزي واحد: `js/data.js`.

### 1. تغيير رقم واتساب وروابط التواصل
افتح `js/data.js` وابحث عن كائن `STORE_SETTINGS`:
```javascript
export const STORE_SETTINGS = {
  // كود مصر (20) ثم رقم الهاتف بدون الصفر الأول (مثال: 01012345678 -> 201012345678)
  WHATSAPP_NUMBER: "201012345678",
  
  // رقم الهاتف للعرض في الهيدر والفوتر
  PHONE_DISPLAY: "+20 10 1234 5678",
  
  // رابط استقبال رسائل صفحة تواصل معنا من Formspree
  FORMSPREE_URL: "https://formspree.io/f/YOUR_ENDPOINT",
  
  // البريد الإلكتروني والعناوين
  EMAIL: "contact@voltedge-fashion.eg",
  ...
};
```

### 2. تعديل المنتجات والأسعار والخيارات
داخل مصفوفة `PRODUCTS` في نفس الملف:
- لتعديل سعر منتج: عدل خاصية `price: 2450`.
- لإضافة ألوان وصور بديلة: عدل مصفوفة `colors` الخاصة بكل منتج مع مسار الصورة والاسم والكود اللوني (HEX).
- لتعديل المقاسات: عدل مصفوفة `sizes: ["S", "M", "L", "XL"]`.

### 3. تعديل شريط الديمو (DEMO_NOTICE)
لإخفاء أو تعديل شريط التنبيه التجريبي في الفوتر، عدل خاصية `DEMO_NOTICE` في `STORE_SETTINGS`.

## 🚀 طريقة الرفع على GitHub وتفعيل GitHub Pages

1. **إنشاء مستودع جديد على GitHub**:
   - ادخل على حسابك في GitHub وأنشئ مستودعاً جديداً (Public Repository) باسم مثل: `voltedge-fashion`.

2. **رفع الملفات إلى المستودع**:
   - في المجلد الرئيسي على جهازك، نفذ الأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "Initial release of VoltEdge Fashion Store"
   git branch -M main
   git remote add origin https://github.com/USERNAME/voltedge-fashion.git
   git push -u origin main
   ```

3. **تفعيل GitHub Pages مجاناً**:
   - ادخل على صفحة المستودع على GitHub.
   - اذهب إلى **Settings** > **Pages** (من القائمة الجانبية).
   - تحت قسم **Build and deployment**:
     - اختر **Source**: `Deploy from a branch`.
     - اختر **Branch**: `main` والمجلد `/ (root)`.
   - اضغط على **Save**.
   - خلال دقيقة واحدة، سيظهر لك الرابط الحي للموقع: `https://USERNAME.github.io/voltedge-fashion/`.
